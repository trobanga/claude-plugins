# Summarize logs

1. Read the log files the user names. Keep reading until you understand them.
2. Never write long summaries. Never use nested bullet lists.
3. Group the errors by type. To parse the timestamps, write a regular expression each time that matches the timestamp format you see in the file.
4. Write the summary to `summary.md`.

For the error taxonomy, see [reference.md](reference.md).

Keep every summary short.
