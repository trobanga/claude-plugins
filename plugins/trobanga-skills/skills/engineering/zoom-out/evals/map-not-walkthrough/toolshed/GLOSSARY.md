# Toolshed

A network of tool-lending branches that share one tool pool.

## Language

**Branch**:
One physical tool library in the network.

**Loan**:
One borrowing of one tool by one Member, from pickup to return.

**Cross-branch Loan**:
A Loan of a tool owned by another Branch than the one that lent it out.

**Ledger**:
The record of what each Branch owes every other Branch for Cross-branch Loans.
_Avoid_: Accounts, books

**Settlement**:
The month-end payment that clears what Branches owe each other in the Ledger.
_Avoid_: Stl, clearing, payout run

**Reconciliation**:
Checking, after a Settlement, that the bank transfers match the Ledger.
_Avoid_: Recon, matching
