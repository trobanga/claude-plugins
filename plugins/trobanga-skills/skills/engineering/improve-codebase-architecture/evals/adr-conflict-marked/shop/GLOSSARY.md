# Shop

An online shop for hand tools.

## Language

**Order**:
A Customer's confirmed request to buy items, with a price fixed at confirmation.
_Avoid_: Purchase, transaction

**Order intake**:
Turning a Cart into a confirmed Order: check it, price it, store it.
_Avoid_: Checkout processing, order handling

**Cart**:
Items a Customer has picked but not yet ordered.

**Notification**:
A message telling a Customer what happened to their Order.
_Avoid_: Alert, ping
